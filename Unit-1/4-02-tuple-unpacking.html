TUPLE UNPACKING

x, y = 1, 2

NOTE: x is assigned 1 and y is assigned 2.

x, y = y, x       # swap
print(x)          # 2
print(y)          # 1

TYPE CONVERSION

int(), float(), str(), bool()

NOTE: Passing another type as the parameter performs the respective conversion.

int("25")   # str to int, result 25
int(4.99)   # result 4
