UNIT 1.2 - VARIABLES, IDENTIFIERS & TYPES

(1)

Variables: Store a value under a name for reuse.

SYNTAX - ASSIGNMENT STATEMENT

<identifier> = <literal>
<identifier>
name given to the value
=
assignment operator
<literal>
a fixed value, e.g. 10, "Alex"

NOTE: Binding value to an identifier is called as variable.

EXAMPLE

age = 10    # no output. value stored.
print(age)  # prints 10

LITERALS

int       float     str       bool
15        1.45      "Hello"   True
