(4)

STRING INDEXING

Extract a character from str using index.

{str-identifier}[{index}]
{index} - {positive-index | negative-index}
{positive-index}
0, 1, 2, 3, ...
{negative-index}
-1, -2, -3, ...

INDEX MAPPING

str         H    e    l    l    o
+ve index   0    1    2    3    4
-ve index  -5   -4   -3   -2   -1

EXAMPLE

str = "Hello"
print(str[-4])  # prints e
