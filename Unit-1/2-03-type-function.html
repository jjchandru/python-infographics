UNIT 1.2 - VARIABLES, IDENTIFIERS & TYPES

(3)

SYNTAX - type() FUNCTION

type({identifier|literal})
{identifier|literal}
value whose type is being checked

EXAMPLE

type(5)          # no output
print(type(5))   # <class 'int'>

DYNAMIC TYPING

Reassigning another type on existing identifier.

age = 5     # type of age is 'int'
age = "5"   # type of age is 'str'
