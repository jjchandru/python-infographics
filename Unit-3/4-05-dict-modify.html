UNIT 3.4 - DICTIONARIES

(5)

Modifying an existing value by assignment

EXAMPLE

student = {"name": "Ravi", "age": 20, "dept": "CSE"}

student["age"] = 21
print(student)

Output:
{'name': 'Ravi', 'age': 21, 'dept': 'CSE'}

EXPLANATION

  • Same syntax as ADD — dict_name[key] = value.
  • Because "age" already exists, the old value (20) is overwritten instead of a new pair being created.
  • No new key is added and the dict's length does not change.
