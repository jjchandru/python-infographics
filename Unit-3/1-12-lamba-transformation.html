UNIT 3.1 - LISTS

(12)

From def to lambda — same function, one line

NORMAL FUNCTION (def)

def square(x):
    return x * x

print(square(5))

TRANSFORMATION

def square(x):
    return x * x

LAMBDA EXPRESSION

Lambda Expression Transformation Steps:

  1. Remove the struck-out parts
  2. Bring together remaining parts in the same line
  3. Prefix with "lambda" keyword
  4. This expression now represents a function without a name, called an anonymous function
  5. It has no name of its own, but a variable can still point to it and call it
lambda x: x * x

SYNTAX - LAMBDA

lambda {lambda-expression}
{lambda-expression} - {parameters}: {expression}
lambda
Keyword that creates an anonymous function
{lambda-expression}
The parameter(s) and body together
{parameters}
Comma-separate for multiple: x, y
{expression}
Single expression, returned automatically (no return keyword)
