UNIT 3.1 - LISTS

(17)

Mapping and filtering in one expression

EXAMPLE

temps = [30, 32, 29, 35, 31, 28, 33]

hot_plus_3 = [x + 3 for x in temps if x > 32]
print(hot_plus_3)

Output:
[38, 36]

SYNTAX - LIST COMPREHENSION

[{expression} {for-loop-statement-no-colon} {conditional-statement-no-colon}]
