UNIT 3.4 - DICTIONARIES

(9)

Looping through keys using keys()

EXAMPLE

student = {"name": "Ravi", "age": 20, "dept": "CSE"}

for key in student.keys():
    print(key)

Output:
name
age
dept

EXPLANATION

  • keys() gives just the keys, one per iteration.
  • for key in student: does the same thing — looping over a dict directly loops over its keys, so .keys() is optional but makes the intent explicit.
  • Use student[key] inside the loop if the value is also needed.
