UNIT 3.1 - LISTS

(4)

Slicing a list with start, stop, and step

SYNTAX - SLICE

{list_identifier}[{start}:{stop}:{step}]
{start}, {stop}, {step} - {literal | identifier | expression}
{start}
Index to begin the slice (default: 0)
{stop}
Index to end the slice, non-inclusive (default: length of list)
{step}
Interval between picked indices (default: 1); negative value reads the list backward
Result
Always a new list

EXAMPLE

temps = [30, 32, 29, 35, 31, 28, 33]

print(temps[1:6:2])

start, stop, step = 1, 6, 2
print(temps[start:stop:step])

print(temps[0+1:2*3:4//2])
