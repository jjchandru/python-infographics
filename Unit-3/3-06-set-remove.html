UNIT 3.3 - SETS

(6)

Removing an item from a set with remove()

ITEM EXISTS

cart = {"pen", "notebook", "eraser"}

cart.remove("pen")
print(cart)

Output:
{'notebook', 'eraser'}

ITEM MISSING

cart = {"pen", "notebook", "eraser"}

cart.remove("marker")

Output:
KeyError: 'marker'

EXPLANATION

  • remove() deletes the item if it exists in the set.
  • If the item is not in the set, remove() raises a KeyError.
  • Use remove() when a missing item should be treated as a bug.
