UNIT 3.3 - SETS

(2)

Creating a set and watching duplicates disappear

EXAMPLE

numbers = {4, 2, 2, 3, 4, 1, 3}

print(numbers)
print(len(numbers))

OUTPUT

{1, 2, 3, 4}
4

EXPLANATION

  • Sets use curly braces {} — list [], tuple ().
  • Seven values typed, only 4 distinct values kept.
  • len(numbers) confirms it — 4, not 7.
  • Set item order is unpredictable.
