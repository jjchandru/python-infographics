UNIT 3.4 - DICTIONARIES

(17)

Counting votes into a dictionary, built from scratch

SOLUTION

def count_by_fruit(votes):
    counts = {}
    for fruit in votes:
        counts[fruit] = counts.get(fruit, 0) + 1
    return counts

votes = ["Mango", "Apple", "Mango", "Banana", "Mango", "Apple"]

print(count_by_fruit(votes))

Output:
{'Mango': 3, 'Apple': 2, 'Banana': 1}

EXPLANATION

  • counts starts empty — there's no special-case handling for a fruit's first vote.
  • counts.get(fruit, 0) + 1 is the same accumulate-with-get() idiom from the earlier puzzle: 0 the first time a fruit appears, the running count every time after.
  • One line inside the loop handles every fruit, first vote or fiftieth.
