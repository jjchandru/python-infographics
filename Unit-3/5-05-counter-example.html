UNIT 3.5 - ITERATORS

(5)

The built-in shortcut for counting into a dictionary

EXAMPLE

votes = ["Mango", "Apple", "Mango", "Banana", "Mango", "Apple"]

# what you already know
counts = {}
for fruit in votes:
    counts[fruit] = counts.get(fruit, 0) + 1
print(counts)

# same result, one line
from collections import Counter
counts = Counter(votes)
print(counts)

# convert back to a plain dict
plain_dict = dict(counts)
print(plain_dict)

Output:
{'Mango': 3, 'Apple': 2, 'Banana': 1}
Counter({'Mango': 3, 'Apple': 2, 'Banana': 1})
{'Mango': 3, 'Apple': 2, 'Banana': 1}

EXPLANATION

  • Counter(votes) does in one line what the counts.get(fruit, 0) + 1 loop did by hand.
  • Counter behaves like a dict everywhere it matters — square brackets, .items(), looping, all work the same.
  • print() labels it as Counter({...}) instead of plain {...}, just so you can tell what created it — day to day you use it exactly like the dicts you already know.
  • dict(counts) converts it into a plain dict, if you specifically need one — plain_dict now prints without the Counter(...) label.
