UNIT 3.4 - DICTIONARIES

(13)

Looking up a key safely with get()

SQUARE BRACKETS - KEY MISSING

student = {"name": "Ravi", "age": 20, "dept": "CSE"}

print(student["year"])

Output:
KeyError: 'year'
note
This is overcome by using the get() function — see the next box.

GET()

student = {"name": "Ravi", "age": 20, "dept": "CSE"}

print(student.get("age"))
print(student.get("year"))
print(student.get('Year', 2026))

Output:
20
None
2026

EXPLANATION

  • student["year"] raises a KeyError because "year" is not a key in the dict.
  • student.get("year") checks for the key the same way, but returns None instead of raising — the program keeps running.
  • student.get("Year", 2026) shows the optional second argument — a fallback value returned instead of None when the key is missing.
  • Use get() whenever a missing key is a normal possibility, not a bug.
