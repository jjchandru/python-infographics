UNIT 3.2 - TUPLES

(6)

Basic tuple operations — concatenation, repetition, and membership

CONCATENATION

weekdays = ("Mon", "Tue", "Wed")
weekend = ("Sat", "Sun")

full_week = weekdays + weekend
print(full_week)

Output:
('Mon', 'Tue', 'Wed', 'Sat', 'Sun')

REPETITION

colors = ("red", "green", "blue")
extended = colors * 2
print(extended)

Output:
('red', 'green', 'blue', 'red', 'green', 'blue')

MEMBERSHIP

valid_grades = ("A", "B", "C", "D", "F")

print("B" in valid_grades)
print("E" in valid_grades)

Output:
True
False

EXPLANATION

  • + concatenates two tuples into a new, longer tuple — neither original tuple is changed.
  • * repeats a tuple's items — colors * 2 builds a new tuple with the items doubled up.
  • in / not in checks whether a value exists anywhere in the tuple, returning True or False.
  • All three operations produce a new tuple or a boolean — none of them modify the original tuple, staying consistent with immutability.
