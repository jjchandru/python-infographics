UNIT 3.4 - DICTIONARIES

(19)

Collecting names into a dictionary of lists, built with setdefault()

SOLUTION

votes = [
    ["Ravi","Mango"],
    ["Anu","Apple"],
    ["Kiran","Mango"],
    ["Divya","Banana"],
    ["Sara","Mango"],
    ["Rahul","Apple"]
]

result = {}
for name, fruit in votes:
    result.setdefault(fruit, []).append(name)

print(result)

Output:
{'Mango': ['Ravi', 'Kiran', 'Sara'], 'Apple': ['Anu', 'Rahul'], 'Banana': ['Divya']}

EXPLANATION

  • for name, fruit in votes unpacks each inner list the same way it would a tuple — position 0 into name, position 1 into fruit.
  • result.setdefault(fruit, []) is the list version of the same idea behind counts.get(fruit, 0) on the previous solution — except here the "default" is an empty list, and it gets inserted into the dict, not just returned.
  • .append(name) then grows that list in place, whether it was just created or already had names in it.
