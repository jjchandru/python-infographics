UNIT 3.3 - SETS

(8)

Building a set in one expression, with mapping and filtering

EXAMPLE

words = ["apple", "banana", "cherry", "avocado", "blueberry", "fig"]

letters = {w[0] for w in words if len(w) > 4}
print(letters)

Output:
{'a', 'b', 'c'}

SYNTAX - SET COMPREHENSION

{{expression} {for-loop-statement-no-colon} {conditional-statement-no-colon}}
