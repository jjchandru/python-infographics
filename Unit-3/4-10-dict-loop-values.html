UNIT 3.4 - DICTIONARIES

(10)

Looping through values using values()

EXAMPLE

student = {"name": "Ravi", "age": 20, "dept": "CSE"}

for value in student.values():
    print(value)

Output:
Ravi
20
CSE

EXPLANATION

  • values() gives just the values, one per iteration — no keys at all.
  • Use this form when you only care about the data itself, e.g. summing all the ages in a list of records.
  • There is no student[value] shortcut here — without .items() or .keys(), the matching key is not available inside this loop.
