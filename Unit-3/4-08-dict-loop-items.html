UNIT 3.4 - DICTIONARIES

(8)

Looping through key-value pairs together using items()

EXAMPLE

student = {"name": "Ravi", "age": 20, "dept": "CSE"}

for key, value in student.items():
    print(key, "->", value)

Output:
name -> Ravi
age -> 20
dept -> CSE

WITHOUT UNPACKING

student = {"name": "Ravi", "age": 20, "dept": "CSE"}

for pair in student.items():
    print(pair[0], "->", pair[1])

Output:
name -> Ravi
age -> 20
dept -> CSE

EXPLANATION

  • items() gives each pair as a (key, value) tuple, unpacked here into two loop variables.
  • Use this form when you need both the key and the value inside the loop body.
  • The unpacking is optional — key, value = pair is just a convenience. Without it, pair is still a tuple, so pair[0] and pair[1] work exactly as they did on Unit 3.4's sorting page.
