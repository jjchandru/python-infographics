UNIT 3.3 - SETS

(5)

Adding an item to a set with add()

EXAMPLE

cart = {"pen", "notebook", "eraser"}

cart.add("marker")
print(cart)

cart.add("pen")
print(cart)

Output:
{'pen', 'notebook', 'eraser', 'marker'}
{'pen', 'notebook', 'eraser', 'marker'}

EXPLANATION

  • add() inserts a new item into the set.
  • Adding an item that already exists does nothing, no error, no duplicate.
