UNIT 3.2 - TUPLES

(3)

Packing a student record into a tuple and unpacking it into named variables

EXAMPLE

student = ("Rahul", 20, "IT")

name, age, dept = student

print(name)
print(age)
print(dept)

OUTPUT

Rahul
20
IT

EXPLANATION

  • ("Rahul", 20, "IT") is packing.
  • name, age, dept = student is unpacking.
  • The variable count on the left must match the tuple's length exactly.
  • Always use parentheses when packing.
