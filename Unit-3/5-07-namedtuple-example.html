UNIT 3.5 - ITERATORS

(7)

A tuple whose slots have names, not just positions

EXAMPLE

from collections import namedtuple

Student = namedtuple("Student", ["name", "age", "dept"])

s = Student("Ravi", 20, "CSE")

print(s.name)
print(s[0])

Output:
Ravi
Ravi

EXPLANATION

  • s.name reads like a label instead of a position, but s[0] still works too — it's still an ordinary tuple underneath.
  • s.name = "Kiran" would fail, same as any other tuple — it's still immutable, only the reading got friendlier.
