UNIT 3.1 - LISTS

(5)

Updating an item and demonstrating mutability

EXAMPLE

colors = ["red", "green", "blue"]

colors[1] = "yellow"
print(colors)

OUTPUT

['red', 'yellow', 'blue']

EXPLANATION

  • Using the assignment operator with an index, a specific list item's value can be modified.
  • Lists are mutable — the list object stays the same, only that cell's value changed.
