UNIT 3.4 - DICTIONARIES

(4)

Adding a new key-value pair by assignment

EXAMPLE

student = {"name": "Ravi", "age": 20, "dept": "CSE"}

student["year"] = 2
print(student)

Output:
{'name': 'Ravi', 'age': 20, 'dept': 'CSE', 'year': 2}

EXPLANATION

  • dict_name[key] = value adds a new pair when the key does not already exist.
  • The new pair is added at the end; dictionaries keep insertion order.
  • No error is raised, whether or not the key already existed — see MODIFY for that case.
