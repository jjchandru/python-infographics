UNIT 3.5 - ITERATORS

(4)

Simulating a live data stream with a generator

SOLUTION

import random

def sensor_readings(start):
    current = start
    while True:
        current += random.uniform(-1.0, 1.0)
        yield round(current, 1)


readings = sensor_readings(25.0)

print(next(readings))
print(next(readings))
print(next(readings))

Output (values will differ every run — that's
the point, each reading is generated live):
24.6
25.3
24.9

EXPLANATION

  • current lives inside the generator and survives between calls — each next(readings) resumes right where it paused, still remembering the last value.
  • A plain random.uniform() call couldn't do this alone — it has no memory of the last reading, so it can't drift from it. Something has to hold onto current between calls, and the generator's paused state does that for free.
  • The while True means the sensor can be polled forever — there's no fixed number of readings decided in advance, matching a real device that just keeps running.
