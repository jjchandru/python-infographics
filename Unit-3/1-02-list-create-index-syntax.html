(2)

LIST CREATION

Store multiple values in a single ordered, mutable collection.

{list_identifier} = [{item1}, {item2}, {item3}, ...]
{item1}, {item2}, ...
Comma-separated values (can mix types)
[ ]
Encloses the list

LIST INDEXING

Access a single item from the list using its index.

{list_identifier}[{index}]
{index} - {positive-index | negative-index}
{positive-index}
0, 1, 2, 3, ...
{negative-index}
-1, -2, -3, ...

INDEX MAPPING

list       red     green   blue
+ve index  0       1       2
-ve index  -3      -2      -1
