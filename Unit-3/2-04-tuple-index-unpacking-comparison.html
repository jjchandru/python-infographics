UNIT 3.2 - TUPLES

(4)

Comparing index access and unpacking for reading tuple items

BY INDEX

student = ("Rahul", 20, "IT")

print(student[0])
print(student[1])
print(student[2])

BY UNPACKING

student = ("Rahul", 20, "IT")

name, age, dept = student

print(name)
print(age)
print(dept)

EXPLANATION

  • Both blocks provide same output.
  • Index access - must remember the position.
  • Unpacking - assigns each value to a variable name.
