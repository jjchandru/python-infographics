How the dot operator connects you to an object

OBJECTS, ATTRIBUTES & FUNCTIONS

A fountain pen is an object — it holds data and can perform actions.

ink_level
Attribute — how many ml of ink it holds
open(), close(), write()
Functions — actions the pen can perform

SYNTAX - DOT OPERATOR

{object}.{attribute}
{object}.{function_name}({args})
pen.ink_level
pen.open()
pen.write("hello")
pen.close()

The dot operator reaches into an object to access its attributes or call its functions.
