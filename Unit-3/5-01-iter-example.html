UNIT 3.5 - ITERATORS

(1)

A list supports indexing. An iterator does not.

LIST vs ITERATOR - INDEXING

numbers = [1, 2, 3]  # list is iterable
print(numbers[1])

it = iter(numbers)  # 'it' is an iterator
print(it[1])

Output:
2
TypeError: 'list_iterator' object is not subscriptable

NEXT() AND EXHAUSTION

numbers = [1, 2, 3]
it = iter(numbers)

print(next(it))
print(next(it))
print(next(it))
print(next(it))

Output:
1
2
3
StopIteration

EXPLANATION

  • iter(numbers) converts the list into an iterator — a different kind of object, not just the same list in a new wrapper.
  • An iterator has no positions to jump to — it[1] fails because "give me item 1" is a list operation, not an iterator one.
  • next(it) is the only way to get values out — one at a time, always in order, never backwards.
  • Once all values are used up, next(it) raises StopIteration instead of returning anything — the iterator doesn't reset or loop back to the start.
  • Use an iterator when you only need to walk through values once, in order, and don't need to jump around — e.g. reading a huge file line by line without loading the whole thing into memory first. A for loop already does this under the hood: it calls next() for you until StopIteration stops it.
