UNIT 3.4 - DICTIONARIES

(7)

Deleting a key-value pair and keeping its value with pop()

KEY EXISTS

student = {"name": "Ravi", "age": 20, "dept": "CSE"}

removed_dept = student.pop("dept")
print(student)
print(removed_dept)

Output:
{'name': 'Ravi', 'age': 20}
CSE

KEY MISSING

student = {"name": "Ravi", "age": 20, "dept": "CSE"}

student.pop("year")

Output:
KeyError: 'year'

EXPLANATION

  • dict_name.pop(key) removes the pair and returns the value — unlike del, which returns nothing.
  • Missing key with no default still raises a KeyError, same as del.
  • A second argument sets a fallback instead of erroring — student.pop("year", None) returns None instead of raising.
