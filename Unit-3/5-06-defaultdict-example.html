UNIT 3.5 - ITERATORS

(6)

The built-in shortcut for grouping into a dictionary of lists

EXAMPLE

votes = [
    ["Ravi","Mango"],
    ["Anu","Apple"],
    ["Kiran","Mango"],
    ["Divya","Banana"],
    ["Sara","Mango"],
    ["Rahul","Apple"]
]

# what you already know
result = {}
for name, fruit in votes:
    result.setdefault(fruit, []).append(name)
print(result)

# same result, no setdefault needed
from collections import defaultdict
grouped = defaultdict(list)
for name, fruit in votes:
    grouped[fruit].append(name)
print(grouped)

# convert back to a plain dict
plain_dict = dict(grouped)
print(plain_dict)

Output:
{'Mango': ['Ravi', 'Kiran', 'Sara'], 'Apple': ['Anu', 'Rahul'], 'Banana': ['Divya']}
defaultdict(<class 'list'>, {'Mango': ['Ravi', 'Kiran', 'Sara'], 'Apple': ['Anu', 'Rahul'], 'Banana': ['Divya']})
{'Mango': ['Ravi', 'Kiran', 'Sara'], 'Apple': ['Anu', 'Rahul'], 'Banana': ['Divya']}

EXPLANATION

  • defaultdict(list) means "if a key doesn't exist yet, automatically create it with an empty list" — so grouped[fruit].append(name) never fails, even on a fruit's first appearance.
  • No setdefault() call needed at all — the default behaviour is built into grouped itself.
  • print(grouped) labels it as defaultdict(<class 'list'>, {...}), same reason Counter showed its own label — it still behaves like a dict everywhere it matters.
  • dict(grouped) converts it into a plain dict, same trick as the Counter page.
