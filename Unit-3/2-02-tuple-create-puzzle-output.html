UNIT 3.2 - TUPLES

(2)

Creating a tuple and accessing items by index

EXAMPLE

student = ("Ananya", 21, "CSE")

print(student[0])
print(student[2])
student[1] = 22
print(student)

OUTPUT

Ananya
CSE
TypeError: 'tuple' object does not support item assignment

EXPLANATION

  • Tuples use parentheses () instead of [].
  • Indexing works exactly like lists.
  • Tuples are immutable. Cannot add, modify, or remove items.
  • Due to error, the final print(student) never runs.

WHEN TO USE A TUPLE

  • Use tuple for record of fixed set of fields:
    • Student - (name, age, department)
    • RGB colour red - (255, 0, 0)
    • GPS coordinates - (lat, lon)
  • Use list when the collection needs to grow, shrink, or change.
