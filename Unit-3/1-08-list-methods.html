UNIT 3.1 - LISTS

(8)

Built-in list methods

METHOD REFERENCE

MethodParametersHow it works
appenditemAdds item to the end of the list
insertindex, itemInserts item at the given index
removevalueRemoves the first matching value
popindex (default: last)Removes item at index and returns it
extendlistAdds all items from the list to the end
indexvalueReturns the index of the first matching value
countvalueReturns how many times value occurs
clear—Removes all items from the list

EXAMPLE

colors = ["red", "orange", "green", "yellow"]

removed = colors.pop()
print(removed)   # yellow
print(colors)    # ['red', 'orange', 'green']

colors.extend(["pink", "black"])
print(colors)    # ['red', 'orange', 'green', 'pink', 'black']

print(colors.index("green"))  # 2
print(colors.count("red"))    # 1

colors.clear()
print(colors)             # []
