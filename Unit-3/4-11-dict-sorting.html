UNIT 3.4 - DICTIONARIES

(11)

Sorting a dictionary's pairs by key, or by value

SORT BY KEY

scores = {"Ravi": 88, "Anu": 95, "Kiran": 72}

for key in sorted(scores):
    print(key, "->", scores[key])

Output:
Anu -> 95
Kiran -> 72
Ravi -> 88

SORT BY VALUE

scores = {"Ravi": 88, "Anu": 95, "Kiran": 72}

for key, value in sorted(scores.items(), key=lambda pair: pair[1]):
    print(key, "->", value)

Output:
Kiran -> 72
Ravi -> 88
Anu -> 95

EXPLANATION

  • sorted(scores) sorts the keys directly — a dict, like a list, is sortable because sorted() just needs something iterable.
  • Sorting by value needs .items() plus a key= function, because sorted() has no way to know "value" means the second half of each pair on its own.
  • sorted() always returns a new list — the original dict's insertion order never changes; there is no in-place .sort() for dictionaries.
