UNIT 3.3 - SETS

(3)

Combining and comparing sets — union, intersection, difference, symmetric difference

UNION

python_students = {"Rahul", "Priya", "Aisha"}
java_students = {"Priya", "Karan", "Aisha"}

print(python_students | java_students)

Output:
{'Rahul', 'Priya', 'Aisha', 'Karan'}

INTERSECTION

python_students = {"Rahul", "Priya", "Aisha"}
java_students = {"Priya", "Karan", "Aisha"}

print(python_students & java_students)

Output:
{'Priya', 'Aisha'}

DIFFERENCE

python_students = {"Rahul", "Priya", "Aisha"}
java_students = {"Priya", "Karan", "Aisha"}

print(python_students - java_students)

Output:
{'Rahul'}

SYMMETRIC DIFFERENCE

python_students = {"Rahul", "Priya", "Aisha"}
java_students = {"Priya", "Karan", "Aisha"}

print(python_students ^ java_students)

Output:
{'Rahul', 'Karan'}

EXPLANATION

  • | : union - all items from both sets.
  • & : intersection - items in both sets.
  • - : difference - items only in the first set, items common in both sets are removed.
  • ^ : symmetric difference - removes items present in both sets.
  • The order of names in the output is not predictable.
