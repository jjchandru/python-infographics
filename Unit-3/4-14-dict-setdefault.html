UNIT 3.4 - DICTIONARIES

(14)

get() with a side effect: insert the key if it's missing

SETDEFAULT()

student = {"name": "Ravi", "age": 20, "dept": "CSE"}

result = student.setdefault("year", 1)
print(student)
print(result)

Output:
{'name': 'Ravi', 'age': 20, 'dept': 'CSE', 'year': 1}
1

EXPLANATION

  • setdefault(key, default) is get() with a side effect: if the key is missing, it inserts it with the default value.
  • It also returns the value now stored under that key — here, 1.
