UNIT 3.4 - DICTIONARIES

(12)

A dictionary within a dictionary — one record per key

EXAMPLE

college = {
    "21CS045": {
        "name": "Ravi",
        "age": 20,
        "dept": "CSE"
    },
    "21CS046": {
        "name": "Anu",
        "age": 19,
        "dept": "IT"
    }
}

print(college["21CS045"])
print(college["21CS045"]["name"])

Output:
{'name': 'Ravi', 'age': 20, 'dept': 'CSE'}
Ravi

EXPLANATION

  • The outer dict is keyed by RRR number — unique per student, so it works as a lookup index for the whole college.
  • Each value is itself a dict — the student's own record (name, age, dept).
  • college["21CS045"] jumps straight to that one student's record, no scanning through every entry.
  • Chain a second key to reach a single field inside that record: college["21CS045"]["name"].
