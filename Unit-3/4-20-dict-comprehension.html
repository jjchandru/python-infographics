UNIT 3.4 - DICTIONARIES

(20)

Building a dictionary in one expression, with mapping and filtering

BUILDING

squares = {n: n ** 2 for n in range(1, 6)}
print(squares)

Output:
{1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

SYNTAX - DICT COMPREHENSION

{{key-expr}: {value-expr} {for-loop-statement-no-colon}}

EXPLANATION

  • Same shape as a list comprehension — a loop compressed into one expression — except each result needs a key: value pair instead of a single item.
