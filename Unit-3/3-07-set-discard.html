UNIT 3.3 - SETS

(7)

Removing an item from a set with discard()

EXAMPLE

cart = {"pen", "notebook", "eraser"}

cart.discard("eraser")
print(cart)

cart.discard("marker")
print(cart)

Output:
{'pen', 'notebook'}
{'pen', 'notebook'}

EXPLANATION

  • discard() deletes the item if it exists in the set.
  • If the item is not in the set, discard() does nothing, no error.
