UNIT 5.1 - FILE HANDLING

(7)

The json module turns JSON text straight into Python values.

WHAT IS JSON?

  • JSON (JavaScript Object Notation) is a lightweight, text-based format for storing and exchanging structured data.
  • It looks just like a Python dict — key-value pairs inside { }, and lists inside [ ].
  • Widely used for config files, APIs, and exchanging data between programs written in different languages.

FILE: product.json

{
  "name": "Apple",
  "price": 40
}

PROGRAM

import json

file = open("product.json", "r")
data = json.load(file)
print(data)

file.close()

OUTPUT

{'name': 'Apple', 'price': 40}

EXPLANATION

  • json.load(file) reads the file object and parses its JSON text into a Python value in one step.
  • Since the file holds a JSON object ({...}), json.load returns a Python dict with the same keys and values.
  • print(data) shows the dict — note price comes back as a real Python int (40), not "40" like CSV did. JSON remembers the original type; CSV is always plain text.
  • file.close() releases the file once reading is finished.
