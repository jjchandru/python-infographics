QUESTION

Brief how exceptions can be handled in Python. If an arithmetic expression in Python divides a number by zero, it results in ZeroDivisionError. Write an example program that demonstrates handling ZeroDivisionError.

ANSWER

An exception in a line can be handled by enclosing that line within a try block. The try block must be followed by an except block, which is executed if the exception occurs at execution time.

try:
    a = 10
    b = 0
    result = a / b
    print("Result:", result)
except ZeroDivisionError:
    print("Cannot divide by zero.")
