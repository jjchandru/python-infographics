UNIT 5.1 - FILE HANDLING

(1)

Read a text file line by line, then close it.

FILE: example.txt

Line 1
Line 2

PROGRAM

file = open("example.txt", "r")

for line in file:
    print(line, end="")

file.close()

OUTPUT

Line 1
Line 2

EXPLANATION

  • open("example.txt", "r") opens the file in read mode and gives back a file object stored in file.
  • for line in file: walks through the file object one line at a time; each line still carries its trailing newline character.
  • print(line, end="") prints that line as-is, skipping print's own newline so lines don't get double-spaced.
  • file.close() releases the file back to the OS once you're done reading it.
