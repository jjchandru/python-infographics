Not everything you need is built into the language — some tools live in libraries.

WHAT IS A LIBRARY?

  • A library is a collection of Python code organized as modules and packages.
  • A library may be just a single module, or a package containing many modules.

MODULE vs. PACKAGE

  • Module — a single .py file containing a set of functions and classes.
  • Package — a folder containing multiple modules.

PYTHON STANDARD LIBRARY

  • Ships with every Python installation — no separate download needed.
  • Contains modules and packages for common requirements outside the core language: datetime, math, random, csv, and more.
  • Still needs import before use.

THIRD-PARTY LIBRARY

  • Not part of the Python installation.
  • Downloaded separately using the pip command (e.g. pip install openpyxl).
  • Once installed, it is imported just like any other library.

IMPORTING A LIBRARY

import math
math.sqrt(16)

from math import sqrt
sqrt(16)

EXPLANATION

  • import x loads the whole library — everything inside it is accessed as x.name.
  • from x import y pulls out one specific tool, used directly without the prefix.
