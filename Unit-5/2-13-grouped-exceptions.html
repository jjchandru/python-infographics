UNIT 5.2 - ERRORS & EXCEPTIONS

(13)

One except block, multiple exception types

CODE

try:
    num = int(input("Enter a number: "))
    result = 10 / num
    print("Result:", result)
except (ValueError, ZeroDivisionError):
    print("Enter a non-zero number.")

EXPLANATION

  • Multiple exception types can be grouped into one except clause using a tuple: except (ValueError, ZeroDivisionError):.
  • This block runs if either exception occurs — useful when the same handling logic applies to more than one exception type.
  • This is different from writing separate except blocks, which is needed only when each exception type requires its own, different handling.
