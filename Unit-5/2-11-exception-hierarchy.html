UNIT 5.2 - ERRORS & EXCEPTIONS

(11)

Every exception belongs to a family tree

THE EXCEPTION HIERARCHY

BaseException
   Exception
      ValueError
      TypeError
      ZeroDivisionError
      KeyError
      ...

EXPLANATION

  • Every exception in this tree is a class
  • BaseException is the root of everything Python can raise. Exception is the branch normal programs catch.
  • All the familiar ...Error classes — ValueError, TypeError, ZeroDivisionError — are subclasses of Exception, not a separate category.
  • If we write except Exception:, it matches every exception below it in the tree too — so it ends up handling all of them, not just one specific kind.
