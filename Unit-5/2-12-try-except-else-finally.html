UNIT 5.2 - ERRORS & EXCEPTIONS

(12)

The full shape: multiple except, else, finally

CODE

try:
    print("try block")
except ValueError:
    print("ValueError occurred")
except ZeroDivisionError:
    print("ZeroDivisionError occurred")
else:
    print("else: runs when no exception")
finally:
    print("finally: always runs")

EXPLANATION

  • Python checks the except blocks in order and runs the first one whose exception type matches.
  • else runs only when the try block completes with no exception at all.
  • finally always runs — exception or not, handled or not — commonly used for cleanup.
