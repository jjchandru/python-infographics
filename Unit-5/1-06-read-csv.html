UNIT 5.1 - FILE HANDLING

(6)

The csv module splits each line into values at the commas.

FILE: products.csv

Name,Price
Apple,40
Bread,35
Milk,25

PROGRAM

import csv

file = open("products.csv", "r")
reader = csv.reader(file)

for row in reader:
    print(row)

file.close()

OUTPUT

['Name', 'Price']
['Apple', '40']
['Bread', '35']
['Milk', '25']

EXPLANATION

  • csv.reader(file) wraps the file object so each line is split into a list of values at the commas.
  • for row in reader: gives one row at a time as a list of strings — the header row comes first, just like any other row.
  • print(row) shows each row as a Python list; note the price is a string ("40"), not a number — everything read from a file starts out as text.
  • file.close() releases the file once all rows have been read.
