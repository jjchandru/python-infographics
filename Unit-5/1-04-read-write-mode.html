UNIT 5.1 - FILE HANDLING

(4)

"r+" lets you read and write the same file, without erasing it first.

FILE: example.txt (before)

Line 1
Line 2

PROGRAM

file = open("example.txt", "r+")
content = file.read()
print(content)
file.write("Line 3\n")
file.close()

OUTPUT

Line 1
Line 2

FILE: example.txt (after)

Line 1
Line 2
Line 3

EXPLANATION

  • open("example.txt", "r+") opens the file for both reading and writing without erasing existing content, unlike "w".
  • file.read() reads the entire content into content and moves the file's position pointer to the end.
  • print(content) shows what was actually read, before anything new is written.
  • file.write("Line 3\n") writes starting exactly where the pointer left off — after read(), that's the end, so it's effectively appended.
  • close() flushes the write to disk.
