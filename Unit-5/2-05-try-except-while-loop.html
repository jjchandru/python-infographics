UNIT 5.2 - ERRORS & EXCEPTIONS

(5)

Now let's keep asking until the input is valid

PROGRAM

while True:
    try:
        age = input("Enter your age: ")
        age = int(age)
        break
    except ValueError:
        print("Invalid number for age.")

print("Age: ", age)

OUTPUT

Enter your age: ten
Invalid number for age.
Enter your age: twenty
Invalid number for age.
Enter your age: 20
Age:  20

EXPLANATION

  • while True repeats the block forever, until something inside it runs break.
  • Each pass: ask for age, try converting it.
  • Fails — except prints the message, no break, so the loop just asks again.
  • Succeeds — int(age) works, break exits the loop with a valid age in hand.
  • This is what actually fixes the frustration from the earlier questions — only the one field gets retried, not the whole form.
