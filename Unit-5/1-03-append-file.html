UNIT 5.1 - FILE HANDLING

(3)

Append mode adds to the end of a file without touching what's already there.

FILE: example.txt (before)

Line 1
Line 2

PROGRAM

file = open("example.txt", "a")
file.write("Line 3\n")
file.close()

FILE: example.txt (after)

Line 1
Line 2
Line 3

EXPLANATION

  • open("example.txt", "a") opens the file in append mode — writing goes to the end of the file, existing content is kept.
  • Like "w", if the file doesn't exist, "a" creates it.
  • close() flushes the buffered write to disk.
