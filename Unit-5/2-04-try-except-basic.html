UNIT 5.2 - ERRORS & EXCEPTIONS

(4)

Let's stop the crash first, using try and except

PROGRAM

try:
    age = input("Enter your age: ")
    age = int(age)
    print("Age: ", age)
except ValueError:
    print("Invalid number for age.")

OUTPUT

Enter your age: ten
Invalid number for age.

EXPLANATION

  • try runs the risky code — the moment int(age) fails, Python jumps straight to except.
  • except ValueError catches it and runs its own block instead of crashing — no traceback this time.
  • The program ends normally. But look closely: it never got the age. The user is not asked again.
