UNIT 5.2 - ERRORS & EXCEPTIONS

(2)

Let's run it and see what actually happens

PROGRAM

age = input("Enter your age: ")
age = int(age)
print("Age: ", age)

OUTPUT

Enter your age: ten

ValueError: invalid literal for int() with base 10: 'ten'

EXPLANATION

  • Line 1 runs fine — age now holds the text "ten".
  • Line 2 fails — int("ten") cannot convert the word "ten" into a number, so Python raises a ValueError.
  • The program stops right there. Line 3 never runs, so print("Age: ", age) does not execute — the age is never printed.
