UNIT 5.2 - ERRORS & EXCEPTIONS

(9)

A colon is missing after the condition

CODE

age = 20
if age > 18
    print("Adult")

OUTPUT

SyntaxError: expected ':'

CODE

print("Hello")
    print("World")

OUTPUT

IndentationError: unexpected indent

EXPLANATION

  • An if statement must end with a colon — it is missing in the first example.
  • The second print line is indented for no reason — Python does not expect a new block there.
  • Python finds both problems while reading the file, before running anything — not even the first line of either snippet executes.
  • These are both syntax errors. IndentationError is simply a specific kind of syntax error — bad spacing, not bad logic.
