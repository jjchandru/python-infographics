UNIT 5.2 - ERRORS & EXCEPTIONS

(15)

Triggering an exception on purpose

CODE

def set_age(age):
    if age < 0:
        raise ValueError("Age cannot be -ve")
    print("Age set to", age)

set_age(-5)

EXPLANATION

  • The raise statement lets our own code trigger an exception on purpose, instead of waiting for Python to raise one.
  • Here, if age is negative, we raise a ValueError with our own message before any invalid value gets used.
  • Once raised, it behaves like any other exception — it can be caught with try/except, or left to crash the program if nothing catches it.
  • To handle exceptions specific to our application, our own custom exceptions can be defined.
