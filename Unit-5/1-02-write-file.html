UNIT 5.1 - FILE HANDLING

(2)

Write mode creates a file, or wipes it clean if it already exists.

FILE: example.txt (before)

(does not exist yet)

PROGRAM

file = open("example.txt", "w")
file.write("Hello\n")
file.write("World\n")
file.close()

FILE: example.txt (after)

Hello
World

EXPLANATION

  • open("example.txt", "w") opens the file in write mode — if the file exists its old content is erased immediately; if it doesn't exist, a new file is created.
  • write() writes the string exactly as given; it does not add a newline for you, which is why "Hello\n" includes one.
  • close() saves the changes to disk and releases the file handle.
