UNIT 5.2 - ERRORS & EXCEPTIONS

(10)

Same word "wrong" — two very different reasons

SYNTAX ERROR — MISSING COLON

age = 20
if age > 18
    print("Adult")

SYNTAX ERROR — BAD INDENTATION

print("Hello")
    print("World")

EXCEPTION — INVALID CONVERSION

age = input("Enter your age: ")
age = int(age)
print("Age: ", age)

EXPLANATION

  • The first two snippets never get a chance to run — Python finds the mistake while reading the whole file. These are syntax errors.
  • The third snippet has no syntax mistake. Python starts running it, and it fails only when int(age) is executed with "ten". This is an exception — a problem that shows up while the code is running.
  • A syntax error stops the program before it starts — there is nothing running yet, so try/except cannot help.
  • An exception happens while code is already running, so it can be caught with try/except — exactly what we did earlier with the while loop.
