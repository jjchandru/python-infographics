Exits the loop immediately, skipping remaining iterations.

SYNTAX - BREAK

while {condition}:
    {0 or more statements}
    if {break_condition}:
        break
    {0 or more statements}

for {var} in {sequence}:
    {0 or more statements}
    if {break_condition}:
        break
    {0 or more statements}

break is typically used inside an if statement to exit when a specific condition is met.
