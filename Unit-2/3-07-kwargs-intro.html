UNIT 2.3 - CONTROL STRUCTURES, FUNCTIONS & TOOLING

(7)

Arbitrary Keyword Arguments (**kwargs)

EXAMPLE CODE

def print_info(**details):
    print(details)

print_info(name="Alex", roll_no=101, grade="A")

print_info(title="Python", author="Guido", price=499)

OUTPUT

{'name': 'Alex', 'roll_no': 101, 'grade': 'A'}
{'title': 'Python', 'author': 'Guido', 'price': 499}

NOTE

The ** symbol collects all named parameters as key-value pairs. Named parameters are stored in dictionary format {key: value}. We will learn how to work with dictionaries in detail in the next module.
