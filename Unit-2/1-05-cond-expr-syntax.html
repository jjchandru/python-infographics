UNIT 2.1 - CONTROL STRUCTURES, FUNCTIONS & TOOLING

(5)

One-line if-else that returns a value, not a block.

SYNTAX - CONDITIONAL EXPRESSION (TERNARY)

{value_if_true} if {condition} else {value_if_false}
{condition}
{boolean-expr. | logical-expr.}
{value_if_true}
{identifier | literal | expr.} — result when condition is True
{value_if_false}
{identifier | literal | expr.} — result when condition is False
note
an expression, not a statement — can be assigned or printed directly
