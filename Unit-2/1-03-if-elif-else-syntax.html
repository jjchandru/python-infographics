UNIT 2.1 - CONTROL STRUCTURES, FUNCTIONS & TOOLING

(3)

Chooses one block among many conditions.

SYNTAX - IF ELIF ELSE (CONDITIONAL STATEMENT)

if {condition}:
    {statement(s)}
[elif {condition}:
    {statement(s)}]*
[else:
    {statement(s)}]
{condition}
{boolean-expr. | logical-expr.}
elif
checked only when all conditions above are False
else
runs when every condition is False
[ ]
optional
*
can be repeated
