UNIT 2.2 - LOOPS

(5)

Iterate a sequence's elements directly, one at a time.

SYNTAX - FOR (SEQUENCE)

for {loop_variable} in {sequence}:
    {statement(s)}
for, in
keywords
{loop_variable}
variable that holds one element from sequence, in order
{sequence}
string, list, tuple, set, or dictionary
{statement(s)}
Assignment Statement or Expression Statement or Conditional Statement. Indent: 4 Spaces.
note
usage of for with list, tuple, set and dictionary will be covered later
