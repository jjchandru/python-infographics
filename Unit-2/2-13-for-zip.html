UNIT 2.2 - LOOPS

(13)

zip(sequence1, sequence2, ...) — pairs items from multiple sequences.

SYNTAX - ZIP(SEQ1, SEQ2, ...)

for {var1}, {var2}, ... in zip({seq1}, {seq2}, ...):
    {statement(s)}
{var1}, {var2}, ...
variables to unpack paired items
{seq1}, {seq2}, ...
two or more iterables to combine together

Stops when the shortest sequence ends.

EXAMPLE

letters = "ABC"
numbers = "123"

for letter, number in zip(letters, numbers):
    print(f"{letter} → {number}")

Output:
A → 1
B → 2
C → 3
