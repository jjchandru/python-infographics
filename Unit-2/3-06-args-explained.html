UNIT 2.3 - CONTROL STRUCTURES, FUNCTIONS & TOOLING

(6)

Arbitrary Arguments List (*args)

REFERENCE CODE

def print_items(*values):
    for value in values:
        print(value)

print_items(1, 2, 3, "test")
print_items(True, 14.5)

EXPLANATION

  • The * symbol before a parameter collects all positional arguments into a sequence.
  • Allows passing any number of arguments to the function when calling it.
  • Inside the function, *values becomes a sequence that can be iterated using for.
  • Useful when the number of arguments is not known in advance.
  • The name *args is a convention; you can use any valid identifier like *values or *items.
