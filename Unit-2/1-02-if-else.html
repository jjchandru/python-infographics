UNIT 2.1 - CONTROL STRUCTURES, FUNCTIONS & TOOLING

(2)

Chooses between two code blocks.

SYNTAX - IF ELSE (CONDITIONAL STATEMENT)

if {condition}:
    {statement(s)}
else:
    {statement(s)}
{condition}
{boolean-expr. | logical-expr.}
else
runs when condition is False

EXAMPLE

marks = 35

if marks >= 40:
    print("Pass")
else:
    print("Fail")

Output:
Fail
