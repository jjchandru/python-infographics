Docstring: Documentation string for functions

EXAMPLE - FUNCTION WITH DOCSTRING

def volume_of_cylinder(radius, height=10):
    """
    Calculate the volume of a cylinder.
    
    Args:
        radius: Radius of the cylinder base
        height: Height of the cylinder (default: 10)
    
    Returns:
        Volume of the cylinder
    """
    pi = 3.14159
    volume = pi * radius ** 2 * height
    return volume

print(volume_of_cylinder(7, 10))

EXPLANATION

  • A docstring is a string literal enclosed in triple quotes """ placed right after the function definition.
  • It documents what the function does, its parameters, and return value.
  • Helps other developers (and your future self) understand the function's purpose without reading the code.
  • Can be accessed using help(function_name) or function_name.__doc__.
  • Good practice to include docstrings for all functions, especially in larger projects.
