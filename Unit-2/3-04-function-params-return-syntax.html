Function accepting parameters and returning value

SYNTAX - FUNCTION WITH PARAMETERS

def {function_name}({param1}, {param2}):
    {code_block}
    return {expression}
{param1}, {param2}
Parameter names (identifiers)
{expression}
Value to return to caller

SYNTAX - DEFAULT PARAMETER

def {function_name}({param1}, {param2}={value}):
    {code_block}
    return {expression}
{param2}={value}
Default value if not provided

CALL - POSITIONAL ARGUMENTS

{function_name}({arg1}, {arg2})
{arg1}, {arg2}
Values passed in order

CALL - KEYWORD ARGUMENTS

{function_name}({param2}={arg2}, {param1}={arg1})
{param}={arg}
Order-independent (name-based)

CALL - USING DEFAULT

{function_name}({arg1})
Omitted parameter
Uses default value from definition
