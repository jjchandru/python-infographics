UNIT 2.1 - CONTROL STRUCTURES, FUNCTIONS & TOOLING

(1)

Runs a code block when condition is True.

SYNTAX - IF (CONDITIONAL STATEMENT)

if {condition}:
    {statement(s)}
{condition}
{boolean-expr. | logical-expr.}
{statement(s)}
Assignment Statement or Expression Statement or Conditional Statement. Indent: 4 Spaces.

EXAMPLE

marks = 45

if marks >= 40:
    print("Pass")

Output:
Pass
