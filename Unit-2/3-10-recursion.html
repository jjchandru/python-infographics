Recursion: A function calling itself

EXAMPLE - FACTORIAL

def factorial(n):
    # Base case: Stop recursion
    if n == 0 or n == 1:
        return 1
    
    # Recursive case: Call itself
    else:
        return n * factorial(n - 1)

print(factorial(5))  # Output: 120

KEY POINTS

  • Call current function within a function.
  • Recursion runs into infinite loop and is stopped by Base Case.
  • Recursive case contains the main logic.
  • Do not use recursion for simple looping algorithms like factorial, use them in case of advanced sorting algorithms or tree traversal.
