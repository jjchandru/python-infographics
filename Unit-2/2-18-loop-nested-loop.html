UNIT 2.2 - LOOPS

(18)

A loop inside another loop — outer loop runs once, inner loop completes fully.

NESTED LOOPS - CONCEPT

A nested loop is a loop placed inside the body of another loop.

PROBLEM - APARTMENT NUMBERING

An apartment complex has:

  • 3 Blocks: A, B, C
  • Each block: 3 floors
  • Each floor: 2 apartments
  • Total per block: 6 apartments

Task: Print all apartment numbers for each block.
Format: A1, A2, A3, A4, A5, A6 (then B1-B6, C1-C6)
