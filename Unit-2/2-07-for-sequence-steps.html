UNIT 2.2 - LOOPS

(7)

Iterate a sequence's elements directly, one at a time.

CODE

name = "Ravi"

for letter in name:
    print(letter)

TRACE - STEP BY STEP

StepStatementDescription
1name = "Ravi""Ravi" assigned to 'name'
2for letter in name:'R' extracted and stored in 'letter'
3print(letter)prints 'R'
4for letter in name:'a' extracted and stored in 'letter'
5print(letter)prints 'a'
6for letter in name:'v' extracted and stored in 'letter'
7print(letter)prints 'v'
8for letter in name:'i' extracted and stored in 'letter'
9print(letter)prints 'i'
note
loop ends when the {sequence} is exhausted — no explicit condition check, unlike while
