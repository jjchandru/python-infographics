UNIT 2.2 - LOOPS

(16)

Skips the current iteration and continues with the next one.

SYNTAX - CONTINUE

while {condition}:
    {0 or more statements}
    if {skip_condition}:
        continue
    {0 or more statements}

for {var} in {sequence}:
    {0 or more statements}
    if {skip_condition}:
        continue
    {0 or more statements}

continue is typically used inside an if statement to skip certain iterations based on a condition.
