UNIT 2.2 - LOOPS

(12)

enumerate(sequence) — returns (index, value) pairs when looping.

SYNTAX - ENUMERATE(SEQUENCE)

for {index}, {value} in enumerate({sequence}):
    {statement(s)}
{index}
position in the sequence, starting from 0
{value}
actual item from the sequence
{sequence}
any iterable (list, tuple, string, etc.)

EXAMPLE

word = "PYTHON"

for index, char in enumerate(word):
    print(f"{index}: {char}")

Output:
0: P
1: Y
2: T
3: H
4: O
5: N
