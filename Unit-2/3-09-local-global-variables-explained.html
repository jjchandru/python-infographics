Local and Global Variables

REFERENCE CODE

count = 10

def print_count():
    count = 20
    print("Inside function:", count)

print_count()
print("Outside function:", count)

GLOBAL VARIABLE

Variable defined outside any function, accessible throughout program. In the code, count = 10 is global.

LOCAL VARIABLE

Variable defined inside a function, accessible only within. The count = 20 inside print_count() is local.

VARIABLE SCOPE

Region of code where a variable can be accessed. Local count exists only inside the function body.

KEY RULE

Assignment inside a function creates a new local variable. That's why the global count remains 10.
