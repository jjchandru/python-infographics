UNIT 2.2 - LOOPS

(1)

Repeats a code block while condition stays True.

SYNTAX - WHILE (LOOP STATEMENT)

while {condition}:
    {statement(s)}
{condition}
{boolean-expr. | logical-expr.} — re-checked before every iteration
{statement(s)}
Assignment Statement or Expression Statement or Conditional Statement. Indent: 4 Spaces.
How it works?
  1. If {condition} is true the {statement(s)} are executed.
  2. After execution of statements, the {condition} in while is checked again
  3. If {condition} is still true, the {statement(s)} are executed again
  4. This process continues until {condition} becomes false
